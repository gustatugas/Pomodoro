# Pomodoro — Foco e Produtividade

Um projeto desenvolvido para auxiliar na organização dos estudos e na concentração durante as tarefas do dia a dia. A aplicação reúne um temporizador Pomodoro, uma lista de tarefas e um histórico diário de tempo de estudo, com um campo florido em pixel art como plano de fundo.

## Funcionalidades

- **Temporizador Pomodoro:** seleção do tempo de foco entre 5 e 60 minutos.
- **Tempo de descanso:** escolha de períodos de descanso de 5, 10 ou 15 minutos.
- **Controles do temporizador:** iniciar, pausar, continuar e reiniciar a contagem.
- **Lista de tarefas:** adicionar, concluir e remover tarefas.
- **Armazenamento local:** mantém as tarefas e o estado do temporizador salvos no navegador.
- **Histórico de estudos:** registra e exibe o tempo total de foco do dia.
- **Plano de fundo animado:** vídeo em pixel art para compor a interface.
- **Design responsivo:** adapta a disposição dos elementos para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/gustatugas/Pomodoro.git
   ```

2. Acesse a pasta do projeto.
3. Verifique se os arquivos HTML, CSS, JavaScript e o vídeo estão nos caminhos referenciados pelo código.
4. Abra o arquivo `index.html` no navegador.
